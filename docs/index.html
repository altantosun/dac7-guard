Häufige Fragen (DAC7 / PStTG)

Ab wann melden Kleinanzeigen, eBay & Vinted ans Finanzamt?

Nach EU-Richtlinie DAC7 (in Deutschland PStTG § 4 Abs. 5) melden Plattformen Verkäufer pro Kalenderjahr und pro Plattform, sobald mindestens 30 Transaktionen ODER mehr als 2.000,00 € Bruttoerlös erreicht werden.

Muss ich bei einer Meldung automatisch Steuern zahlen?

Nein. Der private Verkauf von gebrauchtem Hausrat (Kleidung, Möbel, altes Smartphone) unter dem ursprünglichen Einkaufspreis ist steuerfrei. Erst bei kurzfristigen Verkäufen mit Gewinn innerhalb eines Jahres greift in Deutschland die 1.000-€-Freigrenze (§ 23 EStG).

Werden meine Verkaufsdaten irgendwohin übertragen?

Nein. DAC7 Guard besitzt keine Server, keine externen Abhängigkeiten und sendet null Netzwerk-Requests. Der gesamte Code ist öffentlich unter der MIT-Lizenz auf GitHub einsehbar.
